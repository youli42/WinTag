# WinTag

外挂式 Windows 窗口语义增强工具 —— 为窗口对象添加临时语义标记，在多窗口并行工作时快速追踪每个窗口正在执行什么任务，将短期记忆外挂在可视化界面上。

## 核心痛点

在 AI 协作场景下，同时开启多个对话窗口形成并行"思维线程"。AI 生成内容需要时间，用户被迫在任务间频繁切换，导致：

- **目标迷失**：回到窗口时忘记当初开启对话的目的
- **任务遗忘**：AI 已输出完毕，但彻底忘了曾开启过这个任务
- **管理混乱**：窗口堆叠时缺乏视觉索引，难以快速定位

## 解决方案

WinTag 在 Windows 窗口管理之上增加一层**元数据图层**，让用户随时了解每个窗口"正在执行什么命令、目的是什么"，通过自定义标签和便签，秒级恢复工作上下文。所有数据仅存在于当前会话，程序退出即清除。

## 核心功能

| 模块 | 功能 |
| :--- | :--- |
| 窗口感知与定位 | 自动检测活动窗口，以窗口句柄唯一标识，仅会话内有效 |
| 标签与便签UI | 左上角悬浮标记，鼠标悬停展开便签（标题+备注），快捷键快速添加 |
| 全局概览面板 | 快捷键呼出聚合列表，展示所有已标记窗口，快速跳转，搜索过滤 |

## 技术栈

- **语言**：Rust
- **GUI 框架**：egui 或 Tauri（待定）
- **系统 API**：windows-rs (Win32)
- **存储**：无持久化，仅会话内内存存储
